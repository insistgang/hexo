# 第26周复盘（6月22日 ~ 6月28日）

> 📌 本篇为 7/1 补写（当周周末未做）。补写时 6/29-6/30 已过、论文已推进到"准备投稿"，相关前瞻详见 [[2026-06月复盘]]。

## 本周总结

比赛清空后的第一个完整周，主线是**把论文实验主线坐实 + 开始还身体债 + 一次高质量南京社交**。6/22 租下 4090、实验开跑，之后论文主线 7 天没断；6/25 是全周枢纽——前一天散掉后，主动把运动（断 11 天）、作息、专注三条一起纠回来；6/27-28 南京会议带来全周情绪峰值。但两个反复模式也现了原形：**一有空档就往外摊新东西**（研创赛构想、Linklab 投赛）、**作息相位卡在 12 点起、黄金时段几乎全废**。整体是上升的一周（精力/情绪双回升、0 通宵），弧线明显好于上周。

## 关键成就

1. **★ 论文实验主线坐实** —— 6/22 服务器太贵 → 改租同学C的 4090，配环境、部署、开跑；实验后台持续一周。**论文主线 7 天几乎每天都碰**（跑实验 / 改模块 / GPT Pro 改稿 / 改 yds / 和导师对齐），这是清空比赛后最想要的状态。
2. **★ 身体债开始还** —— 运动断 11 天后 6/25 健身接回、6/26 爬坡巩固（连续 2 天）；且**全周 0 通宵**（vs 上周 3 次），睡眠债没再累加。
3. **★ 一次高质量南京社交** —— 6/27-28 南京参会：上台汇报 AI+X、认识一位同行、和老友深聊到凌晨。被看见 + 有连接，是全周情绪峰值，也是带着劲回来推论文的补给。
4. **6/25「回正日」的自我修正** —— 6/24 散掉（3:40pm 起 + 新构想）后，6/25 主动把作息前拨 4.5h、运动接回、守住专注三件一起纠回来——自我修正机制在起作用。
5. **行政按截止交付** —— 表彰 / 宝钢 / 事迹材料 6/24 交辅导员、6/26 表彰会按时参加；Linklab 简体化打包完成。

## 模式识别

### 精力/状态趋势

- 平均精力：**6.6/10**（较上周 5.3 明显回升）
- 平均情绪：**6.6/10**（较上周 5.9 回升）
- 精力高峰：**6/27（8/10）** —— 南京会议日，全天在线 + 深度社交
- 情绪高峰：**6/27-28（8/10）** —— 南京被看见 + 有连接
- 情绪低谷：**6/23（5/10）** —— 晚间和同学A聊完学术"状态不对劲"（未展开）
- 专注高峰：**6/22、6/25（⭐⭐⭐⭐）** —— 纯专注日 / 回正日
- 专注低谷：**6/24、6/26（⭐⭐⭐）** —— 表彰材料 + 网页 + 研创赛构想 / Linklab 分流
- **趋势**：一条"专注开局（6/22）→ 中段波动散射（6/23-24）→ 回正（6/25）→ 巩固带分流（6/26）→ 南京社交冲高（6/27-28）"的弧线，情绪与"是否守住专注 + 有无社交补给"同步。

### 时间分配（定性）

- **论文 / 实验**：~45%（本周绝对主线，7 天几乎每天）
- **南京社交**（6/27-28）：~20%
- **行政 / 党务 / 材料**（表彰 / 宝钢 / 会议 / 帮发展对象）：~15%
- **新竞赛分流**（研创赛构想 / Linklab 投赛 ~3h）：~8%
- **运动 / 健身**：~5%
- **休息 / 碎片**：~7%
- ⚠️ **黄金时段（9:00-12:00）**：前中段（6/22-26）几乎全睡，仅 6/25 接住最后 1 小时——这是本周最硬的时间分配问题。

### 成功模式（值得复制）

- **6/22 纯专注日 + 6/25 回正日**是本周两个高质量日，共同点：**减并行 + 不开新摊子 + 一次一件**（延续 6/20 验证的配方）。
- **6/25 证明自我修正有效**：散掉的第二天能主动纠回来，比"从不散"更真实可持续。

### 待改进领域（病灶）

- **作息相位**：前中段普遍 12 点起、6/24 甚至 3:40pm，黄金时段几乎全废；6/27-28 被南京掰早（8:20→6:40）是被动带动，不是主动前拨。
- **训练结果差（6/26 冒头）**：当前论文最大卡点，本能想"堆工作量"补——但堆量通常补不了差结果，应先诊断（数据 / 方法 / 指标 / baseline）。这条拖着，是下周（6/29 起）第一要接的。
- **反复的新摊子苗头**：6/24 研创赛构想、6/26 Linklab 投赛（3h 分流）——比赛刚清空又往外摊，是反复出现的模式（认出来即可，不必苛责）。
