# 2026年8月计划

> **制定时间：2026-08-01；最近校准：2026-08-13。** 原计划依据 7 月复盘、年度中期复盘、第 30 周复盘及待办台账制定。向前执行统一以本篇中期校准为准；原始日记只保留当时事实，不再驱动当前训练。

## 零、8 月 13 日中期校准（当前执行版）

### 为什么改计划

上旬把原来混在一起的三件事拆开了：**训练跑通、数据身份成立、论文证据成立**。前者已经完成很多，后两者仍需补证。当前最重要的不是再跑一组模型，而是先把数据边界说对、落盘并冻结。

### 当前数据决策

| 数据类型 | 当前身份 | 论文用途 |
|---|---|---|
| **本人自采批次** | 来源已确认；保留样本与少量空样本待完成受控清单 | 正式数据版本核心候选；补齐标签、场景分组和泄漏审计后用于场景验证 |
| **旧购买批次** | 非本人自采，研究授权未证明 | 默认退出正式训练、验证、测试和论文结论 |
| **其他第三方批次** | 来源、权利人与研究授权待核 | 只快速检查一次授权证据；无有效证据则封存为当前不可用于正式论文 |
| **现有混合集** | 第三方数据与自采数据存在重合 | 既有结果只作 C 级历史预实验，不能写成自建数据主结果 |

### 当前唯一 WIP 与阶段门

```text
第三方授权证据检查（≤10 分钟）
→ 隔离纯自采清单
→ 标签绑定 + 场景分组 + 泄漏审计
→ 冻结纯自采版本与独立测试集
→ 跑一个确定性正式基线
→ 再决定公开数据算法实验与候选模块
```

若第三方授权仍不可证明，采用“公开数据集做算法比较 + 纯自采数据做场景验证”。公开数据实验属于阶段门后的下一阶段，不抢当前 WIP。

## 二、8 月三大核心目标（专注收敛，绝不扩摊）

### 🎯 目标一：毕业论文——数据证据闭环 + 第一个正式基线 ⭐⭐⭐

**月末完成标准**：
- [x] 完成人工自检口径确认
- [x] 完成远程只读盘点与资产回收
- [x] 明确自采、购买、第三方和混合数据的来源关系与当前论文用途
- [ ] 对第三方数据只做一次 10 分钟授权证据检查，形成最终状态
- [ ] 生成纯自采受控清单，闭环标签绑定、场景分组和泄漏审计
- [ ] 按场景组冻结纯自采版本与独立测试集
- [ ] 在冻结版本上跑一个正式检测基线，保存配置、命令、权重、日志与指标
- [ ] 完成“数据来源与使用边界”正文，建立公开数据算法比较 + 自采场景验证的实验角色表
- [ ] 基线完成后再决定是否进入候选模块，不预排结论

**停止线**：
- 不再打开旧工程；不在混合集上继续追指标；不把历史结果写成自建数据主结果；授权追查不超过 10 分钟；纯自采版本与独立测试集冻结前不开新训练。
