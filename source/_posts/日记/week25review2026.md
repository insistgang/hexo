# 第25周复盘（6月15日 ~ 6月21日）

## 本周总结

本周是**比赛冲刺 → 收尾 → 清空**的一周，主线是把手上一堆比赛交付掉、给论文腾出跑道。两个实打实的进展：**6/18 论文全部实验跑完、6/20 比赛季收官并重新上手写了 500 字正文**。但比这更重要的，是一个**认知上的纠正**——把一直困着自己的解释，从"我在心理上回避写论文"，纠正成了"我只是同时摊太多、比赛先占了优先级"。代价也很清楚：身体债全面亏空（运动 0/7、黄金时段几乎全睡、通宵 3 次、整体作息偏晚）。

## 关键成就

1. **★ 论文实质推进一大步** —— 6/18 全部实验跑完（实验阶段收尾）、6/20 重新上手写 500 字正文并发给老师。论文从"跑实验"推进到"实验完成 + 开始写"。
2. **★ 比赛季收官** —— 6/20 电赛作品提交、6/17 逢甲赛敲定并报备父母、研电赛推进 + 拍视频。多个比赛冲刺收尾，跑道清空。
3. **认知突破：找到真问题 + 有效开关** —— 把"回避被看见"的误解纠正成"注意力分散"；并验证了有效方法 = **清空并行 + 移除干扰（卸载抖音）+ 专注一件**（6/20 亲测：比赛一清、抖音一卸，论文当晚就动了）。
4. **一堆尾巴清掉** —— 软著材料整理完、hexo 隐私脱敏闭环、公安备案 / 618 等行政尾巴。
5. **情绪与家人** —— 心理咨询（第15周）情绪自我修复跑通；父亲节联系家人。

### 时间分配（定性）
- **比赛 / 竞赛**（电赛 / 逢甲 / 研电）：本周最大头，6/15–6/20 几乎每天
- **论文**：看 / 跑实验 / 改 / 6/20 写 500 字
- **帮他人需求 + 党务 + 社交 + 家人**：占用不少（6/16 一整天在响应他人需求）
- ⚠️ **黄金时段（9:00–12:00）7/7 天全在睡**——这是本周最硬的时间分配问题

### 成功模式（值得复制）
- **6/20 是本周最高效的一天**，配方很清楚：比赛清空（并行减少）+ 卸载抖音（移除干扰）+ 晚间单线程 → 当晚发论文 + 写 500 字。
- 复制要点：**减少并行、物理移除干扰、一次只做一件**。

### 待改进领域

## 本周感悟

> 本周最大的收获不是某件事做成，是**想明白了一件事**：把困住自己的解释，从"我在心理上回避写论文 / 回避被看见"（越想越自责、还无解），纠正成了"我只是同时摊太多 + 比赛先占了优先级"（可操作、有解）。6/20 亲测——比赛一清、抖音一卸，论文当晚就动了。**问题从来不是意志或人品，是环境和专注。** 这一条，比这周写的那 500 字更值钱。
