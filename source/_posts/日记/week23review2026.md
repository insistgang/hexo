# 第23周复盘（6月1日 ~ 6月7日）

> 📌 本篇为 7/1 补写（当周周末未做）。是 6 月复盘体系的第一周，也是"习惯启动周"。

## 本周总结

6 月第一周（月计划定的"习惯启动周"）**启动得很艰难**。开局 6/1 就跌到谷底——和学妹吵架两次、自闭刷抖音 5.5h、六级连续 12 天未完成；中段 6/2-6/3 靠导师的项目、研电赛、mac 迁移把状态拉回（精力情绪回到 6）；6/4 快递被骗情绪又掉，6/5-6/6 被行政与社交填满，6/7 彻底恢复日（睡 14h+ 强制还债）。整周被"帮他人 + 行政 + 比赛"占满，**月计划三个核心目标（六级≥50%、论文推进、早睡）几乎全落空**——六级仅 6/2 破了个小冰，论文写作产出≈0，作息全周凌晨睡。是全月最低的一周（精力 4.9 / 情绪 5.0），典型的"计划丰满、现实骨感"。

## 关键成就

1. **导师的项目开发部署完成** —— 6/2 完整开发 + 部署 + 和导师对接（后端数据需求已提出），6/3 又推进研电赛推送 / 自检 / 答疑。横向与比赛这条线本周推得实。
2. **六级僵局小破冰** —— 5/21 起连续 0，6/2 终于碰了（背单词 / 整理备考 / 整合六级项目），虽未坐实但打破了"完全不做"，为下周（六级冲刺周）埋了种子。
3. **mac 迁移工作流搭起来** —— 6/3 论文编排管理系统 + codex/kimi/minimax 任务闭环、6/6 opencode 更新——把主力工作台从 win 迁到 mac。
4. **电赛正式启动** —— 6/7 报名缴费 + 六级备用材料备齐 + 购 Apple Care，电赛这条线进入执行。
5. **行政尾巴推进** —— 6/5 政审表填完、域名备案推进。
6. **高质量帮他人 / 社交** —— 6/4 帮同学 / 导师 / 家人、6/5 帮同学完成 3 篇研报、6/6 和师兄深聊——"被需要"的价值输出，但也占了大量本可给自己的时间。

## 模式识别

### 精力/状态趋势

- 平均精力：**4.9/10**（全月最低周）
- 平均情绪：**5.0/10**（全月最低周）
- 精力高峰：**6/2、6/3、6/6（6/10）** —— 项目 / 社交拉起来的三天
- 精力低谷：**6/1、6/7（3/10）** —— 吵架内耗日 + 恢复还债日
- 情绪高峰：**6/6（7/10）** —— 和师兄吃饭逛街的社交日
- 情绪低谷：**6/1（3/10，和学妹吵架两次）、6/7（3/10，疲惫）**
- 专注高峰：**6/2、6/3（⭐⭐⭐⭐☆）** —— 项目开发 / mac 迁移
- 专注低谷：**6/1（⭐）、6/6（2/5）、6/7（低）**
- **趋势**：情绪明显被外部事件牵动（6/1 吵架、6/4 快递被骗 → 情绪掉；6/2 项目顺、6/6 社交好 → 情绪回）。整周是"消耗 → 小回升 → 再消耗 → 强制恢复"的低位震荡，没有稳定的高能量段。

### 时间分配（定性）

- **横向项目 / 比赛**（导师的项目 / 研电赛 / 电赛）：~30%（本周最大头）
- **帮他人 + 社交**：~20%（6/4 帮多人、6/5 帮同学 3 篇研报、6/6 社交日）
- **党务 / 行政**（政审 / 备案 / 党员材料）：~15%
- **mac 迁移 / 工具链**：~10%
- **论文**：~8% 的"碰"（迁移系统 / 读论文 / 跑 minimax），**写作产出 0%**
- **六级**：~5%（仅 6/2）
- **情绪内耗 / 恢复 / 娱乐**：~12%（6/1 自闭刷抖音 5.5h、6/7 睡 14h+）
- ⚠️ **月计划要的"论文放黄金时段 2h"**：全周黄金时段几乎全在睡，一次没落地。

### 成功模式

- 6/2、6/3 两个较高质量日的共同点：**有明确的外部对接对象**（导师要项目、研电赛要答疑）——有人等着，就推得动。
- 6/7 印证一条：**低能量日切换环境（去图书馆）仍能做成事**（电赛报名 / 六级备料 / 听课）。

### 待改进领域（病灶）

- **六级僵局（月计划第一优先级）**：5/21 起连续未完成，本周仅 6/2 破小冰，"最小启动"机制没立住——这正是月计划最担心的。
- **论文写作产出 = 0**：全周都是"碰"（迁移 / 读 / 跑工具），没有一段真正的正文——和后面几周同一个病灶。
- **作息全面紊乱 + 情绪易被牵动**：0/7 早睡、凌晨常态；6/1、6/4 情绪跟着外部事件大起大落。
- **时间被"别人的事 + 行政"填满**：6/4-6/6 三天大量给了他人需求与社交，"自己的事"被挤到边角。

## 本周感悟

> 6 月第一周是"习惯启动周"，却启动得极不顺——月计划立的三个核心目标（六级、论文、早睡）几乎全落空。但回头看，问题不在不努力，而在**启动周的能量被前段掏空了**：5 月底连轴 + 6/1 吵架内耗 + 连续凌晨睡，身体到 6/7 直接用 14h+ 睡眠强制还债。
>
> 这周真正做成的是"别人的事"（导师的项目、帮同学研报、研电赛答疑）和"绕不开的行政"（政审、备案、电赛报名），而"自己的事"（六级、论文、早睡）全被挤到边角。这不是道德问题，是**排序和能量问题**——想在启动周立新习惯，得先有能量，而这周的能量还在填坑。好在 6/2 的六级小破冰、6/7 的电赛启动，是为下一周（六级冲刺周）埋的两个种子。别苛责这个开局，它是全月弧线的最低点，往后是回升。

## 下周计划（第24周 6.8-6.14）

1. **六级冲刺（第一优先级，6/13 就考）** 🔴 —— 僵局已破小冰，下周直接切冲刺：每天固定时段背单词 / 作文 / 翻译，把 6/13 当硬死线。
2. **论文别只"碰"** —— 至少落 1 段真正的正文，别再停在迁移系统 / 读论文。
3. **止住凌晨睡** —— 6/7 睡 14h 是还债信号，下周先把入睡时间往前拨，别再连续凌晨 3 点。
4. **运动保持** —— 6/7 健身接回了，下周别又断，散步 / 爬坡常态化。
5. **少接新的"别人的事"** —— 帮他人有价值，但本周占太多；下周先保自己的六级 / 论文，再帮忙。
